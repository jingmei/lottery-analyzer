Lottery History Data Analyzer

A personal, open-source, non-commercial tool for organizing and visualizing publicly published lottery draw results.

About Features Privacy Disclaimer Chinese version

1. What this site is

This is a personal, open-source, non-commercial data analysis tool. It takes draw results that have already been published by official lottery organizations and turns them into frequency statistics, trend charts, historical comparisons and local OCR-based number entry, for data research purposes. All code is open source and can be reviewed.

Data sources

Results are compiled from the publicly published draw history of China Welfare Lottery and China Sports Lottery, and are used only for data reference and statistical analysis. This site is not affiliated with, endorsed by, or operated by any lottery issuer, seller or regulator, and is not an official website. If the data differs from an official announcement, the official announcement governs.

Technology and deployment

The front end is a single static HTML file with zero back-end dependencies. Static assets are served from Cloudflare Workers edge nodes. Draw data is fetched from official public endpoints by a machine located in mainland China and then pushed to an edge KV cache; edge nodes never fetch those sources themselves (overseas IPs are blocked by their WAF). A 300-draw snapshot is embedded in the page so it still renders offline, without a blank screen.

The project is released under the MIT License and can be reviewed at github.com/jingmei/lottery-analyzer; a domestic mirror is available at gitee.com/respectfully-mei/lottery-analyzer. Issues are open for feedback and false-positive appeals.

The live demo is at https://maicaipiao.top/ (Chinese interface).

2. Features

  • Six lottery games: Shuangseqiu, Daletou, Kuaile 8, Fucai 3D, Qilecai and Pailie 3.
  • Statistics: frequency over 30 / 50 / 100 draws, omission, trends, odd/even, sum and span, plus charts.
  • Local OCR entry: Tesseract.js runs entirely in the browser; images and recognized text are never uploaded.
  • Local result entry and reminders: saved only in the browser's localStorage.
  • Offline use: a 300-draw snapshot is embedded in the single HTML file.
  • Smart refresh: every 60 minutes normally; after each draw, retries every 10 minutes from +20 minutes until the new period arrives.

Chart and OCR libraries (Chart.js, Tesseract.js) are loaded from cdn.jsdelivr.net for front-end functionality only; they are not used for tracking. Without them the analysis features still work offline.

3. Privacy

This site does not collect, store or upload any personally identifiable information. There is no account system, no login, no server-side form submission, and no third-party analytics or advertising SDK.

  • OCR runs locally in your browser; images and recognized text never leave the device.
  • Result entry and reminders are stored only in your browser's localStorage and can be removed by clearing browser data.
  • Server-side data: the edge KV holds only public historical draw results, never user data.
  • Cookies: no tracking cookies; only local browser storage for interface preferences.
  • Access logs: handled briefly by the hosting platform for normal operation; this site does not read, retain or correlate them with individuals.
