一、站点性质与用途

本站是一个个人开源的历史开奖数据整理与统计分析工具，用于对已公开的开奖结果做频次统计、走势图表、历史对照与拍照录入等数据研究。全部代码开源，可自行审查。

数据来源

开奖信息整理自中国福利彩票、中国体育彩票官方公开发布的历史开奖结果，仅作数据引用与统计分析。本站与各级彩票发行、销售机构没有任何关联，也不是官方网站；数据如有出入，请以官方公布为准。

本站明确不提供

彩票销售代购/合买充值与兑奖 收费服务会员注册广告投放 投注引导中奖承诺

页面中的号码组合是统计模型基于历史频次生成的数据展示结果，用于研究对照，不构成任何投注建议，也不代表真实中奖概率更高。本站不含任何商业推广、跳转购买链接或诱导购彩内容。

技术与部署

前端为单文件静态页面（零后端依赖），静态资源由 Cloudflare Workers 边缘节点提供；开奖数据由部署者本机从官方公开接口抓取后写入边缘 KV 缓存。页面内嵌历史快照，网络不可用时仍可离线查看，不会白屏。

本项目代码以 MIT 许可证开源，全部逻辑可在 Gitee（国内可直接访问） 或 GitHub 中审查；Issues 可用于反馈与误报申诉。

二、隐私说明

本站不收集、不存储、不上传任何能够识别个人身份的信息。没有账号体系，没有登录，没有表单提交到服务器，没有第三方统计或广告 SDK。

  • 拍照识别：OCR 在您的浏览器本地通过 Tesseract.js 完成，图片与识别文字不会上传服务器。
  • 中奖录入与提醒：您填写的内容仅保存在本机浏览器的 localStorage 中，清除浏览器数据即可删除。
  • 服务端数据：边缘 KV 中仅保存公开的历史开奖数据，不含任何用户数据。
  • Cookie：不使用追踪 Cookie；仅使用浏览器本地存储保存界面偏好。
  • 访问日志：由托管平台按常规运行需要短暂处理，本站不读取、不留存、不关联个人身份。

第三方资源

页面从 cdn.jsdelivr.net 加载 Chart.js（图表）与 Tesseract.js（本地 OCR）两个开源库，仅用于前端功能，不用于追踪。若不需要拍照识别功能，可完全离线使用（图表功能需该库）。
