🧩 组合形态校准（和值 / 跨度 / 奇偶 / 大小 / 连号 / 尾数 / 012路）

真实彩民选号除了看冷热与遗漏，还会对整组号码的形状做人工修正：和值是否落在常见区间、跨度是否过大、 奇偶比与大小比是否失衡、连号是否过多、尾数是否过密、012路是否偏枯。 这里先把近 100 期实际开奖的形态统计成「常规区间」（P20~P80），再据此对推荐组做微调校准—— 只换掉出号概率损失最小的号，保证整组出号概率几乎不下降（允许损失 < 1.5%）。

🔍 当期开奖结果 · 预测回顾（逐期滚动累积）

「预测」= 本机上一次生成的第 1 组号码 + 另外 4 个推荐组合，共 5 组同时参与中奖统计（多组并投可扩大号码覆盖、提高「至少中一次」的概率），预测时间即当时生成预测的时刻，精确到秒；每期开奖后自动与该期开奖结果比对，逐期累积成回顾记录。 固定奖中奖金额按官方规则精确计算；浮动奖（一 / 二等奖）优先取当期官方公布的单注金额，官方未公布时标注「浮动」。 本机首次运行之前的历史期次没有存档，会用「当期之前的历史」重跑模型补算一次并明确标注，补算结果不等同于当时的实时预测。 开奖数据取自中国福彩网 / 中国体彩网官方开奖公告。

💰 投注方案 · 期望值分析（结合概率与公开奖级数据）

口径说明：先取最近一期的真实销量与奖池余额，按官方规则原文（分层计提 → 奖池注入 → 单注封顶 → 奖级总额封顶） 还原一等奖 / 二等奖的本期单注奖金，再与每个奖级的命中概率相乘求和，得到「花 N 元能中多少钱」与期望值偏差 ROI； 随后用本模型校准后的出号概率替换随机假设，得到策略增强后的回收。 同一玩法内期望具线性性——任何投注方式的期望值比例都相同，真正会变的是「中奖概率」与「奖金分布形态」。

增益口径 「模型自估」直接采用模型给出的出号概率；「回测实证折损」按 50 期滚动回测中能被统计证实的部分打折，更贴近真实可得的水平。
