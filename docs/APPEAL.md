# 风险提示 / 拦截 申诉指南

适用：手机浏览器提示「此网站疑似含有风险内容」「已停止访问此网页」「网站未完成 ICP 备案」，或微信提示「已停止访问该网页」。

> **先分清两类提示**
> - **微信 ICP 软提示**：「该网站未完成 ICP 备案…如要继续访问，请注意保护个人信息」——可点「继续访问」，不是封禁。海外接入在法律上不需要备案。
> - **浏览器安全库标记**：「此网站疑似含有风险内容，请谨慎访问」/「已停止访问此网页」——来自浏览器背后的安全厂商信誉库（腾讯 / 厂商自建），**与 HTTP 还是 HTTPS 无关**，必须走申诉复审。

> **本项目实测证据（2026-11-04）**
> - 华为手机自带浏览器：弹「风险提示 / 已停止访问此网页 / 此网址存在安全风险」，属软拦截，有「继续访问」。
> - **夸克、UC 浏览器访问完全正常** —— 说明站点本身可访问、内容不是普遍恶意，是华为侧信誉库单点误判。这是申诉时最有说服力的对比证据。
> - 点击网址旁下拉后的站点信息面板里只有「举报」「网站设置」「进入网站设置」「广告过滤」，**没有「网页申诉」**，说明浏览器版本未达官方入口门槛（见 1.1）。

> **当前状态（2026-11-05 17:25 更新）：已解决 ✅**
> 用户复测确认华为手机自带浏览器的风险提示已解除，本站可正常访问。下方排查与申诉步骤保留为方法参考，供同类问题复发时使用；如再次出现拦截，先按「1.1 内置网页申诉」自查浏览器版本，再用夸克 / UC 正常访问作为对比证据。

## 一、华为 / 荣耀手机自带浏览器（本项目实测提示的设备）

官方依据：[华为浏览器三方网页举报和申诉功能](https://consumer.huawei.com/cn/support/content/zh-cn16010257/)

### 1.1 路径 A：内置「网页申诉」（最快，但有版本门槛）

前置条件：**HarmonyOS 5.0 及以上 + 华为浏览器 6.1.7.300 及以上**。

1. 先升级：`我的 > 设置 > 检查更新`（浏览器版本 < 6.1.7.300 时看不到该入口）；
2. 用华为浏览器打开 `https://maicaipiao.top/`，停在风险提示页；
3. 点**网页上方搜索栏内左侧的图标**（锁 / 站点信息图标，依版本不同）→ 「**网页申诉**」；
4. 选申诉类型（网站无风险 / 误报解除），详细填写申诉原因（用第四节模板）；
5. 提交后官方预计 **2~3 个工作日**审核，确认无不良内容会解封。

> ⚠️ 同一菜单里的「**网页举报**」是举报不良网站用的，提交后会**立即屏蔽该页面**；风险面板右上角的「举报」同理。**两个都不要点。**

### 1.2 路径 B：华为官网在线客服 / 950800（找不到入口时主攻这条）

多个第三方实测反馈华为浏览器长期缺少显眼的网址拦截申诉入口，实际有效的是人工工单：

| 渠道 | 地址 / 号码 | 说明 |
|---|---|---|
| 华为官网在线客服 | https://celia.consumer.huawei.com/official | 说明情况后创建服务单，通常当天回电，约 2 个工作日处理 |
| 华为消费者服务热线 | **950800** | 电话反馈，由工作人员协助提交 |
| 浏览器内反馈 | `我的 > 帮助和反馈 > 问题和建议` | 提交日志，勾选「共享应用日志」，记下**问题号或提交时间** |

官方（[zh-cn16103561](https://consumer.huawei.com/cn/support/content/zh-cn16103561/)）明确要求反馈时提供三项，**务必齐备**：

- [ ] **完整的网址**：`https://maicaipiao.top/`
- [ ] **三方浏览器和华为浏览器访问结果对比录屏** ← 你已经有了夸克 / UC 正常访问的截图，补一段「同一时间、同一网络，夸克正常 → 华为被拦」的录屏，说服力最强
- [ ] **华为浏览器问题和建议日志**（路径见上表，附问题号 / 提交时间）

### 1.3 路径 C：腾讯 URLSec（建议与 B 并行提交）

多个来源指出华为内置浏览器的安全拦截数据来自腾讯安全体系，因此同步在腾讯侧申诉往往才是真正清除标记的地方：

| 用途 | 地址 |
|---|---|
| 先查是否被标记 | https://urlsec.qq.com/check.html |
| 网址申诉 | https://urlsec.qq.com/complain.html |
| 网址安全中心 | https://urlsec.qq.com/ |

微信内还有一条更快的路径：**把链接发到任意个人微信聊天 → 点开 → 提示页底部「申请恢复访问」**，按指引提交（本项目之前用「站长认证」验证文件恢复过一次）。

> 若 `check.html` 显示「未拦截」但华为浏览器仍提示，说明标记在华为自有库，回到 1.2 走厂商申诉；静态库查不到不代表没有动态信誉判定。

### 1.4 只解决本机的临时办法（不解除云端标记）

- 风险面板 →「进入网站设置」→ 关闭该站点的「广告过滤」/ 加信任；
- 或 `华为浏览器 > 设置 > 安全与隐私 > 取消勾选「安全浏览」`。

这两项只让你自己这台手机不再弹提示，**别人用华为浏览器照样会拦**，不能替代申诉。

数据全部来自官方已公开的历史开奖结果；拍照识别在用户浏览器本地完成，

收到风险提示后我已逐项整改：
1. 用合规检查脚本清零了所有可能被理解为投注引导/博彩的措辞（BLOCK = 0）；

## 五、常见驳回原因与应对

| 原因 | 应对 |
|---|---|
| 模板化申请、看不出站点性质 | 用口语说明「为什么做、给谁用、不做什么」，别只贴模板 |
| 页面缺隐私政策 / 联系方式 / 服务条款 | 已补 `about.html` 四段 + `security.txt`，申诉时附链接 |
| 彩票类目 + 未备案 + 新域名 + 境外接入 | 高风险组合，可能被反复标记；**ICP 备案是最彻底的解法** |
| 页面仍有诱导购彩措辞 | 重跑 `node scripts/compliance-check.cjs`，确保 BLOCK = 0 |
| 站点被举报过 | 说明来源与整改，附上无广告/无收费的页面截图 |
| 表单要求填备案号 | 如实说明境外接入不适用境内备案，**不要编造备案号** |

## 六、时间预期与长期建议

- 厂商申诉 / 客服工单一般 **1~3 个工作日**，期间页面仍可访问（软提示，可点「继续访问」）。
- 复查方式：提交满 2~3 个工作日后，用**无痕模式或清缓存后**重新打开；必要时换网络（WiFi / 流量）再测，排除本地缓存。
- 不要短时间内重复、密集提交多份工单，容易被判为骚扰而延后处理。
- 解除后建议保持：HTTPS、合规页、无广告无收费、定期跑合规脚本。
- 若反复被标记，最彻底的是完成 **ICP 备案**（需国内服务器与备案主体）；本项目当前选择不备案，因此依赖合规材料 + 申诉维持。
