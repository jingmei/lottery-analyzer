# 风险提示 / 拦截 申诉指南

适用：手机浏览器提示「此网站疑似含有风险内容」「网站未完成 ICP 备案」，或微信提示「已停止访问该网页」。

> **先分清两类提示**
> - **微信 ICP 软提示**：「该网站未完成 ICP 备案…如要继续访问，请注意保护个人信息」——可点「继续访问」，不是封禁。海外接入在法律上不需要备案。
> - **浏览器安全库标记**：「此网站疑似含有风险内容，请谨慎访问」——来自浏览器背后的安全厂商信誉库（腾讯 / 360 / 厂商自建），**与 HTTP 还是 HTTPS 无关**，必须走申诉复审。

## 一、华为 / 荣耀手机自带浏览器（本项目实测提示的设备）

华为浏览器（6.1.7.300+ / HarmonyOS 5.0+）内置**网页申诉**：

1. 打开被提示的网页 → 点**网页上方搜索栏左侧的图标** → 「**网页申诉**」；
2. 选择申诉类型（网站无风险 / 误报），详细填写申诉原因（可用下方模板）；
3. 提交后预计 **2~3 个工作日**审核，确认无不良内容会解封。

其他可用操作：

- 提示面板里的「**进入网站设置**」→ 关闭该站点的「广告过滤」/ 加入信任白名单 —— **只解决本机**，不解除云端标记；
- 面板右上角「**举报**」是**举报网站违规**，不是申诉入口，**不要点错**；
- 也可通过「网页举报与反馈」类入口说明误判。

## 二、腾讯安全体系（QQ / 微信 / 部分国产浏览器共用）

| 入口 | 地址 |
|---|---|
| 网址安全中心（在线服务 → URL 反馈处理） | https://urlsec.qq.com/ |
| 网址申诉 | https://urlsec.qq.com/complain.html |
| 安全检测（先看是否被标记） | https://urlsec.qq.com/check.html |
| 微信公众号「腾讯安全反诈骗实验室」→ 联系我们 → 网址申诉 | 微信内 |

微信内还有一条更快的路径：**把链接发到任意个人微信聊天 → 点开 → 提示页底部「申请恢复访问」**，按指引提交（本项目之前用「站长认证」验证文件恢复过一次）。

> 若 `check.html` 显示「未拦截」但浏览器仍提示，说明标记来自浏览器厂商自有库（如华为），应回到第一节走厂商申诉；静态库查不到不代表没有动态信誉判定。

## 四、可直接复制的申诉说明（建议按自己的话稍作口语化调整）

```
站点：https://maicaipiao.top
合规说明页：https://maicaipiao.top/about.html

您好，我是该站点所有者。这是一个个人开源、非商业的历史开奖数据整理与
统计工具（MIT 协议开源），把官方已公开的开奖结果做成频次统计、走势图表
和本地拍照识别，方便自己做数据研究。

站点不销售彩票、不代购、不充值、不兑奖、不收费、没有广告，没有账号注册，
也没有任何购买或跳转链接。页面中的号码组合只是统计模型对历史频次的输出，
页面顶部与底部都明确写着「彩票开奖为独立随机事件，不存在可预测规律，
不构成投注建议或中奖承诺」，并链接了完整的站点说明、隐私说明与免责声明。

数据全部来自官方已公开的历史开奖结果；拍照识别在用户浏览器本地完成，
不收集、不上传任何个人信息。合规说明见 https://maicaipiao.top/about.html，
安全联系文件见 https://maicaipiao.top/.well-known/security.txt 。

收到风险提示后我已逐项整改：
1. 用合规检查脚本清零了所有可能被理解为投注引导/博彩的措辞；
2. 上线了独立的站点说明、隐私、免责与联系页面，并在页面顶部和底部加链接；
3. 开启强制 HTTPS（Always Use HTTPS、TLS 最低 1.2）、HSTS 等安全响应头；
4. 收敛第三方脚本来源，页面无广告、无弹窗、无诱导跳转。

恳请复核并解除误判。如需补充材料或指明具体问题项，请告知，我会立即整改。
谢谢！
```

## 五、提交材料清单

- [ ] 域名与完整 URL（含 `https://`）
- [ ] 站点用途说明（用上方模板）
- [ ] 合规说明页链接 `about.html`
- [ ] 整改说明（做了什么、什么时候做的）
- [ ] 提示截图（完整，含地址栏）
- [ ] 开源仓库 / 许可证（证明代码可审查）
- [ ] 联系方式

## 六、常见驳回原因与应对

| 原因 | 应对 |
|---|---|
| 模板化申请、看不出站点性质 | 用口语说明"为什么做、给谁用、不做什么"，别只贴模板 |
| 页面缺隐私政策 / 联系方式 / 服务条款 | 已补 `about.html` 四段 + `security.txt`，申诉时附链接 |
| 彩票类目 + 未备案 + 新域名 + 境外接入 | 高风险组合，可能被反复标记；**ICP 备案是最彻底的解法** |
| 页面仍有诱导购彩措辞 | 重跑 `node scripts/compliance-check.cjs`，确保 BLOCK = 0 |
| 站点被举报过 | 说明来源与整改，附上无广告/无收费的页面截图 |

## 七、时间预期与长期建议

- 厂商申诉一般 **1~3 个工作日**，期间页面仍可访问（软提示）。
- 解除后建议保持：HTTPS、合规页、无广告无收费、定期跑合规脚本。
- 若反复被标记，最彻底的是完成 **ICP 备案**（需国内服务器与备案主体）；本项目当前选择不备案，因此依赖合规材料 + 申诉维持。
