## 分级标准

| 级别 | 含义 | 要求 |
|---|---|---|
| **BLOCK** | 博彩黑话、诱导性承诺、金融化表述（押注、盘口、胆码、保底、首推、稳赚、投资收益比…） | **必须为 0** |
| **CAUTION** | 彩票数据分析的固有术语（预测、推荐、中奖、投注、复式、单式…） | 允许存在，但必须有免责声明覆盖 |
| **SAFE** | 否定式合规表述（不保证、不代购、不含广告、独立随机事件…） | 保留，越多越好 |

**为什么保留 CAUTION 类词汇**：这些是彩票数据分析工具无法回避的固有术语，全部替换会让功能失去意义。项目采取的措施是「保留术语 + 强免责覆盖」：

- 页面顶部免责声明（含「独立随机事件、不存在可预测规律、不构成投注建议、不销售彩票、不收费、不含广告」）；
- 每个号码组合模块下方的局部提示；
- 独立合规页 `about.html`（站点性质 / 隐私 / 免责 / 联系与申诉）；
- 页脚三链接（关于本站 / 隐私说明 / 免责声明 / 联系与申诉）；
- 页面标题改为中性的「彩票历史数据统计分析工具」（去掉「智能」「最新数据」等营销措辞）。
